# Library Management System

A web-based Library Management System developed using PHP and MySQL.

##  Project Overview

The Library Management System is designed to manage books, students, and book transactions in a simple and organized way.

It provides an interface for managing library records and keeping track of issued and returned books.

##  Features

- User Registration and Login
- Admin Dashboard
- Add and Manage Books
- Add and Manage Students
- Issue Books
- Return Books
- View Book Records
- View Student Records
- Search Books
- MySQL Database Integration
- Simple and Responsive User Interface

##  Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP
- phpMyAdmin

How to Run
Install XAMPP.
Start Apache and MySQL from XAMPP Control Panel.
Copy the project folder into:
C:\xampp\htdocs\
Create a MySQL database named:
library_db
Import the provided SQL file into phpMyAdmin.
Check the database connection in db.php.
Open the project in your browser:
http://localhost/library_project/
